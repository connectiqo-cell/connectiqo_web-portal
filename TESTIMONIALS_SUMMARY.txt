📝 DATABASE SCHEMA:

Table: testimonials
  id (UUID) - Primary key
  user_name (TEXT) - Required, user's name
  user_title (TEXT) - Optional, user's title/role
  user_avatar_url (TEXT) - Optional, profile image URL
  video_url (TEXT) - Required, video file URL
  thumbnail_url (TEXT) - Optional, video thumbnail
  rating (SMALLINT) - 1-5 stars, default 5
  message (TEXT) - Optional, testimonial text
  created_at (TIMESTAMP) - Auto-populated
  order_index (INTEGER) - For sorting/ordering

Storage Buckets:
  • testimonials-videos (Public) - Video files
  • testimonials-thumbnails (Public) - Thumbnail images
